# Branding provenance and public-release gate

The sole editable icon source is `Assets/RustDeskHop.svg`. It combines the user-approved bunny artwork with a vector ring and white rounded tile. Earlier experiments used RustDesk artwork as a reference; the current mark intentionally resembles RustDesk. The README describes the embedded image hash and construction. Build outputs are derived from this file, not separate original works.

The original RustDesk logo is not licensed by this repository. GPL source licensing does not by itself grant trademark permission, endorsement, or rights to every reference image. User approval of the design is not upstream legal clearance. **Clearance has not been obtained.** Preserve the approved design while resolving this; do not silently substitute another logo.

Before broad public promotion, either obtain and record appropriate written permission for the current mark/name, or have the maintainer approve clearly independent branding and review the replacement's provenance. Obtain legal advice if the scope is unclear. Do not set `brandingCleared` in `release-readiness.json` until the evidence is recorded here.
